# Anil Super Market — Python Project

## About the Project
Anil Super Market is a simple shopping and billing application developed using Python. Users can select products, enter quantities, and calculate the total bill. The application also displays a pie chart of selected products using Matplotlib.

## Features
- Displays a list of 12 products with prices
- Allows users to select products and quantities
- Calculates the total bill
- Displays selected products and prices
- Generates a pie chart using Matplotlib

## Technologies Used
- Python
- Matplotlib

## Python Concepts Used
- Variables and data types
- `while` loops
- `if-elif-else` statements
- Lists and dictionaries
- User input and output
- `for` loops
- Basic data visualization

## How to Run
1. Install Python on your computer.
2. Install Matplotlib:

   ```bash
   pip install matplotlib
   ```

3. Download or clone this repository.
4. Run the Python file:

   ```bash
   python "Super Market Project 1.py"
   ```
